# Oase × Vitamart — Website Resmi

Website resmi **Oase Beverage Bar × Minimarket Vitamart** Karangsentul, Purbalingga.

## 🌟 Fitur Utama
- **Menu Lengkap Oase:** 45 varian menu minuman segar lengkap dengan foto dan harga.
- **Keranjang Belanja Real-Time:** Pengunjung dapat memilih beberapa item, mengatur kuantitas, dan langsung checkout via WhatsApp otomatis.
- **Logic Waktu Operasional Real-Time:** Menghitung waktu WIB (UTC+7) secara otomatis untuk menampilkan status buka/tutup toko (09.00 – 24.00 WIB).
- **Vitamart Corner:** Etalase rokok, ice cream freezer, aneka snack/jajanan, dan minuman kemasan dingin.
- **Peta Interaktif Kedai Vitamart:** Terintegrasi Leaflet Map dengan koordinat terverifikasi dan tombol navigasi langsung ke Google Maps.
- **Delivery Hub:** Terhubung langsung ke ShopeeFood, GoFood, dan GrabFood.
- **Ultra Responsive:** Tampilan mobile-first dengan hamburger navigation drawer modern.

## 🚀 Deployment
File `index.html` dapat langsung di-deploy ke **Vercel**, **Netlify**, atau **GitHub Pages**.
